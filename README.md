# Coop Votação API

API desenvolvida em **Java com Spring Boot** para gerenciamento de pautas e sessões de votação cooperativa, estruturada com Server-Driven UI (SDUI).

## 🛠 Tecnologias Utilizadas
- **Java 17+**
- **Spring Boot** (Web, Data JPA, Validation)
- **H2 Database** (Banco de dados em memória)
- **Lombok**
- **WebClient** (para integração com serviço externo de validação de CPF)
